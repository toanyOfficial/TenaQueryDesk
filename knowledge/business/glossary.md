# 주요 용어
- DB 연결: 관리 DB에 등록된 대상 MySQL 접속 설정입니다.
- connection key: 연결과 스키마 파일을 안정적으로 식별하는 키입니다.
- schema version: 생성된 정적 DB 구조 snapshot의 버전입니다.
- schema object: 테이블 또는 뷰입니다.
- conversation: 질문 흐름 식별자입니다. 현재 요청 간 메시지 영속화는 없습니다.
- tool call: GPT가 등록된 서버 기능의 실행을 요청하는 행위입니다.
- 읽기 전용 SQL: 데이터를 변경하지 않는 SELECT 또는 WITH입니다.
- 업무 정의: 스키마만으로 확정할 수 없는 조직의 규칙과 지표 의미입니다.
